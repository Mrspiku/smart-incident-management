# Smart Incident Management Platform

## Overview

A full stack ticketing system built using:

- React
- ServiceNow
- Scripted REST APIs
- Business Rules
- Flow Designer

## Features

- Incident Creation
- Incident Assignment
- SLA Tracking
- Duplicate Detection
- Approval Workflow
- Dashboards
