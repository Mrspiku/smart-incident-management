# Smart Incident Management Platform

## Project Overview

A full-stack ITSM incident management application built using:

- React Frontend
- ServiceNow Backend
- Scripted REST APIs
- Business Rules
- Flow Designer

---

## Actors

### End User

Responsibilities:

- Login
- Raise Incident
- View My Incidents
- Track Status
- View Resolution

### IT Admin

Responsibilities:

- View New Incidents
- Assign Ticket To Self
- Update Work Notes
- Resolve Incidents
- Close Incidents

### IT Manager

Responsibilities:

- Approve High Priority Requests
- View Reports
- Monitor SLA Compliance
